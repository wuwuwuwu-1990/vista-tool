☁️ GitHub 双端同步 手机+电脑 数据互通

配置方法（一次性）：① 登录 github.com → Settings → Developer settings → Fine-grained tokens → 生成令牌，勾选目标仓库的 Contents: Read and write 权限；② 把令牌粘贴到上方；③ 手机、电脑各自打开本页面并粘贴同一次生成的令牌，数据即互通。
默认仓库：wuwuwuwu-1990/vista-tool（当前站点仓库，已内置数据文件 fanglian-data.json）。令牌只保存在本机浏览器 localStorage，不会上传到任何服务器。保存/修改/删除房源时自动同步，冲突按「谁后改谁生效」合并，删掉的房源不会复活。

📱 配置导入导出 换设备免手输令牌

「复制令牌」：只复制同步令牌本身，换设备时粘贴到访问令牌输入框即可；「复制当前配置」：包含仓库/令牌等全部同步设置，另一台设备粘贴导入一步到位（含令牌，请勿发给他人）。

💾 数据备份

本地数据存于浏览器 localStorage。换设备/清缓存前建议先导出备份；导入时与现有数据智能合并（按记录更新时间），不会覆盖丢失。
