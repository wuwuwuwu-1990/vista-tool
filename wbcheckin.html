手动触发一次云端签到

打开 Actions 页面 → 左侧点「WorkBuddy 每日积分签到」→ 右侧 Run workflow → 保持 main → 绿色按钮。约 30 秒完成，本页状态随即更新。

C
本机命令行查询 / 签到

在电脑上打开「命令提示符」，粘贴以下命令回车（本机无跨域限制，可实时查询）：

C:\Users\Administrator\AppData\Local\Programs\Python\Python312\python.exe "C:\Users\Administrator\WorkBuddy\2026-08-31-00-19-05\workbuddy_checkin\workbuddy_checkin.py" --dry-run
D
Token 失效怎么办

微信会收到告警通知。打开本机文件 %LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info，复制 accessToken 的值（eyJ 开头），到 Secrets 设置 更新 WB_TOKEN 即可，约 1 分钟。

4为什么网页不能直接领取
WorkBuddy 积分接口出于安全限制不允许网页跨域调用（CORS 拦截），因此本网页无法直接点击「签到」按钮—— 无论本地打开还是部署到任何网站都一样。这是接口服务端限制，无法绕过。 解决方案就是本工具的做法：由云端（GitHub Actions）代替浏览器调用接口，网页只做只读状态展示和操作引导。
